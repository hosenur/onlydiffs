---
title: Keyboard shortcuts
description: Use the command menu, move through diffs, stage reviewed files, and control the app without leaving the keyboard.
---

| Shortcut | Action |
| --- | --- |
| Command/Ctrl+K | Open or close the command menu |
| Command/Ctrl+, | Open Settings |
| Control+Command+O on macOS | Open remote projects |
| Command/Ctrl+B | Show or hide the repository sidebar |
| Command/Ctrl+Enter | Stage the selected file |
| `r` | Refresh repository data |
| `s` | Switch between unified and split diffs |
| Enter in the Claude composer | Send the current message |
| Escape in the Claude composer | Close the composer |
| Up or Down on the landing page | Move between the path field and recent projects |

Single-key shortcuts do not run while you type in a field. Command/Ctrl+K and Command/Ctrl+, remain available from text fields.

## Command menu

The command menu also provides actions with no dedicated shortcut:

- Navigate to any changed file
- Add the selected file to staging
- Generate a commit message
- Commit all repository changes
- Switch projects or open a remote repository
- Change between light, dark, and system appearance
- Install an available update

Search matches command labels, changed paths, projects, and remote-host terms.
