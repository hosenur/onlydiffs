## Download the app

The public release currently targets Apple silicon Macs. Download the latest `.dmg` from [GitHub Releases](https://github.com/hosenur/onlydiffs/releases/latest), drag onlydiffs into Applications, and open it.

The release is signed for updates but is not notarized by Apple yet. If macOS reports that the app is damaged or cannot be verified, remove the browser quarantine flag after moving it into Applications:

```bash
xattr -dr com.apple.quarantine /Applications/onlydiffs.app
```

You only need to do this after the first browser download. Updates installed by onlydiffs do not receive the same quarantine flag.

## Requirements

- Git must be installed on the Mac running onlydiffs.
- A repository must have a `.git` entry in its directory or one of its parents.
- Bun and Claude Code are optional. They are needed only for the Claude feedback channel.
- A Groq API key is optional. It enables generated commit messages and project artwork.

Check Git before opening the app:

```bash
git --version
```

## Run from source

```bash
git clone https://github.com/hosenur/onlydiffs.git
cd onlydiffs
bun install
bun run dev:desktop
```

The development command starts Vite and the Tauri shell. For a packaged local build, use `bun run dist` from the repository root.
