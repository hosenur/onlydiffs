title: Review agent-written code without opening an editor
description: onlydiffs is a desktop diff viewer for checking a coding agent's work, staging reviewed files, and sending line-level feedback to Claude.
---

onlydiffs puts the repository on the left and the current diff on the right. It separates staged, unstaged, and untracked changes, keeps full-file context visible, and lets you send a question about any changed line to the Claude session working in that repository.

<Callout title="A reviewer, not an editor">
  onlydiffs does not edit files or replace Git. It gives you a focused place to inspect changes, mark files as reviewed by staging them, and hand precise feedback back to Claude.
</Callout>

## Your first review

<Steps>

### Open a repository

Enter an absolute path, a path relative to your home directory, or any directory inside a Git checkout. onlydiffs finds the repository root and remembers it for next time.

### Read each changed file

Choose a changed path from the repository tree. The diff includes unchanged sections, so you can inspect the change in the context of the whole file. Press `s` to switch between unified and split views.

### Ask about a line

Click a line in the diff, write your message, and press Enter. When a matching Claude Code session is connected, onlydiffs sends the file path, line number, and your message to that session.

### Stage what you have reviewed

Press Command/Ctrl+Enter to stage the current file. A file counts as reviewed only when all changes for that path are staged.

</Steps>

## What is included

- A complete repository tree with changed-file counts, filtering, and file icons
- Separate staged, unstaged, and untracked diffs
- Unified and split diff layouts with word-level highlighting
- Line-level messages to a matching Claude Code session
- Review progress based on staged files
- Generated commit messages and a Commit All command through Groq
- Local and SSH-hosted repositories in the same interface
- Automatic repository refresh, project switching, themes, and signed updates

Start with [installation](/docs/getting-started/installation), then follow [your first review](/docs/getting-started/first-review). The [limits and supported platforms](/docs/reference/limits-and-platforms) page states what the app deliberately does not do.

## Review over SSH

Your code does not have to live on the same machine as the app. Paste the SSH command you already use, open a checkout by its remote path, and review it through the same file tree and diff interface.

onlydiffs uploads a small matching agent to the host. Diff generation, file watching, staging, icon scanning, and Claude delivery happen where the repository lives. The agent uses the existing SSH connection, opens no remote port, and stops when the connection closes.

[Set up an SSH host](/docs/remote-repositories/connect-an-ssh-host) or read [what runs remotely](/docs/remote-repositories/open-a-remote-repository#what-runs-remotely).
